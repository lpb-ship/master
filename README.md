# Seent It foundation

Planning contracts for the mobile-friendly web application.

- [Account lifecycle and shared profile contracts](docs/account-profile-contracts.md): proposed account flows, identity and profile boundaries, navigation, acceptance scenarios, and outstanding decisions.
- [Quality gates and data handling](docs/quality-gates-and-data-handling.md): proposed performance, support, accessibility, operations, and data-lifecycle requirements with approval gates.
- [Shared-activity discovery contract](docs/shared-activity-discovery-contract.md): proposed viewer permissions, derived-data revocation, retention, upstream readiness, and social launch gates.

This repository currently contains documentation only. Provider selection and stakeholder approval are prerequisites for dependent implementation.
